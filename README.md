# Chorcha Full-Stack Clone

This repository contains the full-stack architecture for a free, unlimited exam preparation platform modeled after Chorcha.

## Project Structure
- `backend/`: Node.js Express REST API server, database mock store, and real-time exam endpoints.
- `frontend/`: Responsive web client communicating with the backend API.

## How to Run
1. Start the Backend API:
   ```bash
   cd backend
   npm install
   node server.js
   ```
2. Open the Frontend:
   Open `frontend/index.html` in your web browser.
